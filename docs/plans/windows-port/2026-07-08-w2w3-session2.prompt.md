## 3) Gotchas already learned (don't re-learn)

- Windows PowerShell 5.1 chokes on non-ASCII in .ps1 → keep scripts ASCII (`0919f36`).
- GUI apps don't write qInfo to stdout — `QT_FORCE_STDERR_LOGGING=1` + redirect stderr.
- GStreamer plugins are `gst*.dll` (no `lib` prefix) on MSVC builds; d3d11 decode closure needs the
  extra DLLs bundled (`fb15f72`) — the CI artifact already contains them.
- Export re-encode uses **libopenh264** (LGPL) on Windows — `libx264` is absent by design (`53b6e28`).
- The backend cookie-auths (`access_token`); `WT_CV_AUTOLOGIN=1` handles it in-app.
- If the wall shows one live camera and 31 NO SIGNAL tiles — that's the real fleet state (see §1),
  not a regression.
