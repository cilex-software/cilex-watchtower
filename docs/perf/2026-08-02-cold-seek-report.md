cold runs 2026-08-01 (n=784 total: 216 day + 568 overnight, guard pattern =
random date → 2–4 seeks → next date, hard 08:00 stop). Cold = target ≥120 s
from ALL 6,175 previously-touched offsets across every run and smoke.

target (frameSeq + playheadMs; FrameClock pts deliberately unused — it is
segment-relative on current serves). Measured on the REPAIRED seek path
(d81cbe3: false-MISLANDED loop + dropped re-anchor seeks — both found by this

## Day-open reliability — the worse failure class

100 × 180 s of the night burned on day-opens that never became ready:
`.125` all 3 days = 0 opens/45 attempts (served fine at 18:47 same day —
FLAPPING, backend-side); `.101`(new fleet)/07-31 = 0/15; `.50` 07-19 & 07-22
and `.67` 07-20 flapped (12–15 hangs each between successful opens). For a
guard this is "the date won't open", strictly worse than a slow scrub. CV
letter to follow, together with the new-fleet coverage-vs-sessions
disagreement (sessions return no_recording where coverage says has_footage).
